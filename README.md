# 🧾 Freelance Invoice Generator

A simple and responsive **Freelance Invoice Generator** built with **HTML, CSS, and JavaScript**.

This project allows freelancers and small businesses to quickly create an invoice by entering client details, service information, price, quantity, and tax.

## ✨ Features

* 🧾 Generate a professional invoice
* 👤 Add business and client names
* 💼 Add service details
* 🔢 Set quantity and price
* 💰 Automatic subtotal calculation
* 📊 Automatic tax calculation
* 🧮 Automatic final total
* 📅 Automatic invoice date
* 🖨️ Print invoice
* 📄 Save invoice as PDF using the browser
* 📱 Responsive design
* ⚡ No backend required
* 🔑 No API key required

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Browser Print API

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Enter your business and client information.
5. Enter the service, price, quantity, and tax.
6. Click **Generate Invoice**.
7. Click **Print / Save PDF** to print or save the invoice.

## 🧮 Example

If:

```text
Service: Web Development
Price: $100
Quantity: 2
Tax: 10%
```

The application automatically calculates:

```text
Subtotal: $200
Tax:      $20
Total:    $220
```
